# Azure Lab 17

## Objective
Use Terraform to provision Azure infrastructure as code.

## Commands Used
terraform init
terraform plan
terraform apply
terraform destroy

## What is Terraform
Terraform is an Infrastructure as Code (IaC) tool that lets you define 
your entire cloud infrastructure in configuration files instead of running 
CLI commands one by one. You write what you want, Terraform figures out 
how to create it.

## Result
Successfully provisioned an Azure Resource Group and Storage Account 
using Terraform instead of the Azure CLI.
